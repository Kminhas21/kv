# 30: GitHub Actions CI

**What to build:** Every push and pull request to GitHub runs the checks automatically and shows pass/fail on the commit.

**Blocked by:** None (can start immediately; Terraform steps apply once 29 lands)

**Status:** ready-for-agent

- [ ] Workflow on push and pull_request
- [ ] `go vet ./...` and `go test -race ./...`
- [ ] Benchmark smoke run (`-run '^$' -bench . -benchtime 1x`) so benchmarks keep compiling and running
- [ ] `docker build` of the image
- [ ] `terraform fmt -check` and `terraform validate` (no backend) once Terraform exists
- [ ] No deploy step

**Concepts:** CI as the shared definition of "green", the race detector, why validate without credentials.

**Mock vs production:** production pipelines also push images, run `terraform plan` on PRs, and deploy through gated environments.

**Manual check:** push a branch, watch the Actions tab.
